## About

CareFlow is a web application that helps hospital administrators see current operations (admissions, discharges, bed occupancy, staffing) and uses machine learning to forecast admissions and bed occupancy for the next seven days, flagging possible capacity and staffing shortages. It is an operational planning tool only; it does not make clinical or patient-level decisions.
